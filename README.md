# Rock Paper Scissors Game

A simple browser-based Rock Paper Scissors game developed using HTML, CSS, and JavaScript.

The player selects Rock, Paper, or Scissors, while the computer generates a random choice. The program compares both choices and displays the game result.

## Features

* Rock, Paper, and Scissors selections
* Random computer choice generation
* Win, lose, and tie detection
* Interactive button effects
* Responsive design for smaller screens
* Simple and clean user interface

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How It Works

```text
Player selects Rock / Paper / Scissors
                ↓
Computer generates a random choice
                ↓
Both choices are compared
                ↓
Win / Lose / Tie
                ↓
Result is displayed
```

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/rock-paper-scissors-game.git
```

2. Open the project folder.
3. Open `index.html` in a web browser.
4. Select Rock, Paper, or Scissors to play.
